# Kotlin-Language-Guide

이 리포지토리는 **Kotlin 언어의 핵심 특성, 코루틴(Coroutines)의 동작 원리, 그리고 코틀린스러운(Idiomatic) 코드 작성법**을 학습하고 정리한 노트입니다. 또한, 코틀린 개발에 유용한 **재사용 가능한 템플릿 코드**를 관리하고 있습니다.

## 🎯 학습 목표

1.  Kotlin 언어의 Null Safety, 확장 함수(Extension Function) 등 핵심 문법의 내부 작동 원리 이해.
2.  코루틴 및 Flow를 활용한 비동기 프로그래밍 마스터.
3.  코틀린의 관용구(Idioms)를 기반으로 생산성 증가.

## 📚 목차 (Contents)

| 폴더/파일명                     | 주요 내용                                                                                                                            |
| :------------------------------ | :----------------------------------------------------------------------------------------------------------------------------------- |
| **`01_Core_Features/`**         | 데이터 클래스(Data Class), 씰드 클래스(Sealed Class), Null Safety, 확장 함수 등 **코틀린 핵심 문법 및 특징** 정리.                   |
| **`02_Coroutines_and_Flow/`**   | 코루틴 스코프, 디스패처, 구조화된 동시성(Structured Concurrency), Flow/Channel 등 **비동기 프로그래밍** 심층 정리.                   |
| **`03_Idioms_Best_Practices/`** | `apply`, `with`, `let`, `run` 등 스코프 함수 활용법, 프로퍼티 위임(Delegation), Elvis 연산자 등 **코틀린 관용구 및 모범 사례** 정리. |
| **`04_OOP_and_Generics/`**      | 인터페이스, 추상 클래스, 상속, 제네릭스(Generics)의 타입 소거(Type Erasure) 등 객체 지향 및 고급 주제 정리.                          |
| **`A_Templates/`**              | 코틀린 개발에서 자주 사용되거나 복잡한 로직을 처리하는 데 유용한 **재사용 가능한 코드 템플릿 모음**.                                 |

## 🛠 유틸리티 및 템플릿 (A_Templates)

고차 함수 사용 패턴, 코루틴 예외 처리 등 복잡한 코틀린 로직을 쉽게 시작할 수 있도록 구조화된 템플릿을 제공합니다.

> **활용 방법**: 이 폴더의 코드를 복사하여 코틀린 프로젝트의 기반 로직을 구성하는 데 활용할 수 있습니다.
